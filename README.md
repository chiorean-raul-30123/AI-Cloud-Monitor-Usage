# AI Cloud Usage Monitor

Initial npm-workspaces monorepo skeleton for a personal TypeScript, AWS CDK and Tauri project.

Workspaces: `infrastructure` (CDK), `backend` (future Lambda), `desktop` (future Tauri/React client), and `shared` (shared contracts).

Local commands: `npm install`, `npm run typecheck`, `npm run build`, `npm run cdk:synth`.

The CDK stacks are placeholders. No AWS resources are deployed by this skeleton.
